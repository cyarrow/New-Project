# 元素戰線

雙人回合制卡牌對戰遊戲（原型階段）。以爐石的節奏為基礎，加上兩個自己的機制：

- **成長選擇**：每回合三選一，擴充費用、多抽一張，或累積元素共鳴。費用不會自動成長。
- **三路戰場**：左、中、右三路，隨從只能攻擊同一路的敵人，同一路沒人擋時才能打英雄。

完整規則與卡牌列表見 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)。

## 怎麼玩

不需要安裝任何東西：下載這個專案後，直接用瀏覽器打開 `index.html` 就可以玩。

目前是「同一台電腦兩人輪流」模式。每回合結束會出現換人畫面，避免看到對方手牌；一個人測試時可以在開始畫面勾選「跳過換人畫面」。

操作方式：

1. 回合開始先做**成長選擇**。
2. 點手牌選取，再點要放的路線（隨從）或目標（法術）。
3. 點自己會發光的隨從，再點紅色閃爍的目標攻擊；也可以點「移到這裡」換路線。
4. 按「結束回合」換對手。按 Esc 或點空白處可以取消選取。

## 想改卡牌？

所有卡牌都在 [`src/cards.js`](src/cards.js)。改數字（費用、攻擊、生命）或卡面文字後重新整理網頁就會生效。

## 專案結構

| 檔案 | 用途 |
|---|---|
| `src/cards.js` | 卡牌資料與效果、預組牌組 |
| `src/game.js` | 規則引擎（只有邏輯，之後的電腦 AI 和線上對戰都會共用） |
| `src/ui.js` | 畫面與操作 |
| `styles.css` | 外觀 |
| `tests/engine.test.js` | 規則的自動測試 |
