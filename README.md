# 元素戰線

雙人回合制卡牌對戰遊戲（原型階段）。以爐石的節奏為基礎，加上兩個自己的機制：

- **成長選擇**：每回合三選一，擴充費用、多抽一張，或累積元素共鳴。費用不會自動成長。
- **三路戰場**：左、中、右三路，隨從只能攻擊同一路的敵人，同一路沒人擋時才能打英雄。

完整規則與卡牌列表見 [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)。

## 怎麼玩

不需要安裝任何東西：下載這個專案後，直接用瀏覽器打開 `index.html` 就可以玩。

開始畫面有三種模式：

- **新手教學**：第一次玩從這裡開始，一步一步帶你認識所有規則，大約 3 分鐘。
- **對戰電腦**：一個人練習，可以選「簡單」或「普通」難度。
- **雙人同機**：同一台電腦兩人輪流。每回合結束會出現換人畫面，避免看到對方手牌；一個人測試時可以勾選「跳過換人畫面」。

操作方式：

1. 回合開始先做**成長選擇**。
2. 點手牌選取，再點要放的路線（隨從）或目標（法術）。
3. 點自己會發光的隨從，再點紅色閃爍的目標攻擊；也可以點「移到這裡」換路線。
4. 按「結束回合」換對手。按 Esc 或點空白處可以取消選取。
5. 看不懂某張牌時，**長按**它（電腦可以按右鍵，或選取後按 `i`），會顯示這張牌的效果、目前狀態和名詞說明。

## 想改卡牌？

所有卡牌都在 [`src/cards.js`](src/cards.js)。改數字（費用、攻擊、生命）或卡面文字後重新整理網頁就會生效。

## 專案結構

| 檔案 | 用途 |
|---|---|
| `src/cards.js` | 卡牌資料與效果、預組牌組 |
| `src/game.js` | 規則引擎（只有邏輯，電腦玩家和之後的線上對戰都共用） |
| `src/ai.js` | 電腦玩家 |
| `src/tutorial.js` | 新手教學的步驟與對手劇本 |
| `src/ui.js` | 畫面與操作 |
| `src/motion.js` | 畫面局部更新與動畫（彈簧曲線、出牌飛行、攻擊衝撞、陣亡淡出） |
| `styles.css` | 外觀 |
| `tests/` | 自動測試 |
| `tools/` | 平衡模擬工具 |

## 開發者

執行規則測試（需要 Node.js 18 以上）：

```sh
npm test
```

平衡模擬（讓兩個電腦玩家對打很多局，結果整理在 [docs/BALANCE.md](docs/BALANCE.md)）：

```sh
npm run simulate      # 勝率、對局長度、成長選擇比例、卡牌使用率
npm run experiment    # 比較不同規則數值
npm run matchups      # 所有牌組兩兩對打的勝率表
```
