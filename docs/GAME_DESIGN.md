# 遊戲設計文件（v0.1 草案）

> 暫定名稱：**元素戰線**（之後可改）
> 核心概念：以「元素資源抉擇」為主軸（方向 B），加上「三路戰場」為輔助（方向 A）的 1 對 1 回合制卡牌對戰。
> 目標：一局約 10 分鐘，可單人對電腦，或與一位朋友連線對戰。

---

## 1. 基本規則

| 項目 | 數值 |
|---|---|
| 英雄生命 | 25 |
| 牌組張數 | 20 張（同名卡最多 2 張） |
| 起手 | 先手 3 張、後手 4 張 |
| 手牌上限 | 8 張（滿手時抽到的牌直接棄掉） |
| 費用上限 | 最多 8 點 |
| 勝利條件 | 對手英雄生命歸 0 |
| 牌庫抽乾 | 每次該抽牌卻抽不到時，受到「疲勞」傷害（1、2、3…遞增） |

**後手補償**：後手玩家起始費用上限為 1，而且第一回合的「成長選擇」可以選兩個**不同**的選項。
（v0.2 加入起始費用 1：電腦模擬顯示原本先手勝率約 67%，加入後約 46%。詳見 [BALANCE.md](BALANCE.md)。）

## 2. 回合流程

1. **回合開始**：抽 1 張牌，費用水晶回滿。
2. **成長選擇**（三選一，本遊戲核心）：
   - 💎 **擴充**：費用上限 +1（新增的水晶本回合就能用）
   - 📜 **研讀**：額外抽 1 張牌
   - 🔮 **共鳴**：選一種元素，該元素的「共鳴值」永久 +1
3. **主要階段**：以任意順序進行
   - 打出卡牌（花費費用）
   - 用隨從攻擊
   - 移動隨從（見第 3 節）
4. **回合結束**：換對手。

> **設計重點**：費用**不會**自動成長。每次選「研讀」或「共鳴」，就代表放棄一點費用成長。
> 所以每場的節奏都不一樣：衝費用打大怪、囤手牌、或是累積共鳴打出強化效果。
> 先手起始費用上限為 0，所以第一回合選「擴充」就有 1 費可用；一直選擴充的話，第 N 回合就有 N 費（跟爐石的節奏一樣）。

## 3. 三路戰場

```
        對手英雄
  [ 左路 ] [ 中路 ] [ 右路 ]   ← 對手的隨從
  ─────────────────────────
  [ 左路 ] [ 中路 ] [ 右路 ]   ← 你的隨從
         你的英雄
```

- 每一路每方最多放 **2 隻**隨從，所以每方最多 6 隻。
- 打出隨從時，要選擇放在哪一路。
- **攻擊規則**：
  - 隨從只能攻擊**同一路**的敵方隨從。
  - 如果同一路**沒有**敵方隨從，就可以直接攻擊敵方英雄。
  - 隨從上場那一回合不能攻擊（除非有【衝鋒】）。
- **移動**：花 1 費，把一隻己方隨從移到**相鄰**的路線。移動後的隨從本回合不能攻擊。

> **設計重點**：路線本身就有「擋人」的效果，所以不需要爐石的嘲諷，也能自然產生攻防的取捨。

## 4. 元素

| 元素 | 風格 | 代表能力 |
|---|---|---|
| 🔥 火 | 進攻、爆發 | 直接傷害、衝鋒、高攻低血 |
| 💧 水 | 續航、控制 | 治療、凍結、抽牌 |
| 🌪️ 風 | 機動、干擾 | 疾風、移動、彈回手牌 |
| 🪨 土 | 防守、厚實 | 守護、高血量、加血量 |
| ⚪ 中立 | 基礎 | 任何牌組都能放 |

### 元素機制

- **共鳴 X**：該元素的共鳴值 ≥ X 時，才會啟動的額外效果。
- **連擊**：本回合已經打出過同元素的其他卡時，才會啟動的額外效果。

---

## 5. 關鍵字

| 關鍵字 | 效果 |
|---|---|
| 衝鋒 | 上場當回合就能攻擊 |
| 疾風 | 也能攻擊**相鄰路線**的敵方隨從；同路與相鄰路都沒有敵方隨從時，才能攻擊英雄 |
| 守護 | 同一路的敵人攻擊時，必須優先攻擊有守護的隨從 |
| 凍結 | 被凍結的隨從下一回合不能攻擊 |
| 登場 | 從手牌打出時觸發 |
| 遺言 | 死亡時觸發 |

## 7. 開發路線圖

| 階段 | 內容 | 你可以做什麼 |
|---|---|---|
| **1. 規則原型** ✅ | 網頁版，同一台電腦兩人輪流操作，簡潔卡面 | 試玩、調整數值和規則 |
| **2. 電腦對手** ✅ | 單人模式 AI、新手教學 | 測試 AI 夠不夠聰明 |
| **3. 美術升級** | 卡框、圖示（game-icons.net）、動畫 | 挑選喜歡的風格 |
| **4. 線上對戰** | 開房間、傳連結給朋友連線 | 找朋友實測 |
| **5. 擴充** | 更多卡牌、牌組編輯器、路線地形等 | 設計新卡 |

### 之後可以考慮的擴充點子

- **路線地形**：每場隨機給三條路線各一種元素，同元素的隨從在該路 +1 攻擊（把 A 和 B 綁得更緊）
- **英雄進化**（方向 C）：共鳴值累積到一定程度時，英雄獲得新技能
- **共鳴上限**：如果「共鳴」太強或太弱，可以加上限或改成消耗型

## 8. 待討論的問題

1. 英雄生命 25、費用上限 8：先照這個試玩，再看一局會不會太長或太短。
2. 要不要加入**英雄技能**（像爐石每回合 2 費的技能）？目前先不加，保持簡單。
3. 「擴充」選項是否太強，讓玩家前幾回合永遠都選它？試玩時要特別觀察。
4. 遊戲名稱和世界觀。
