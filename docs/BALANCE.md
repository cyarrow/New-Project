# 平衡模擬報告（v0.2）

讓兩個電腦玩家對打數百局，觀察規則和卡牌的平衡。
重新執行：`npm run simulate`（整體數據）、`npm run experiment`（比較不同規則）。

## 怎麼模擬的

- **電腦玩家**（`src/ai.js`）：每一步都試算所有合法行動，選讓局面分數最高的那個。分數看雙方血量、場上隨從、沒人擋的路線、手牌數。
- **成長策略**：
  - **看手牌**：手上有共鳴卡就累積共鳴，手牌快用完就研讀，其餘時候擴充。
  - **只擴充**：能擴充就擴充。
  - **隨機**：三選一亂選。
- 每組設定打 300～400 局。對局時間用「每回合 40 秒」粗估。

> **注意**：電腦玩家只會看眼前一步，不會規劃整個回合，也不會留牌。真人的打法會更好，所以這些數字是用來發現**明顯的問題**，不是最終答案。

## 發現

### 1. 先手優勢太大 → 已修正

原本的規則下，雙方用同一副牌時，**先手贏 67%**。

已經加入新規則：**後手起始費用上限 1**（原本的「第一回合兩次成長選擇」保留）。加入後先手勝率降到約 **46%**。

### 2. 「擴充」太強（需要你決定怎麼改）

在每一種測試設定下，「只擴充」都贏過「看手牌」，大約是 **65 : 35**。
換句話說，目前選研讀或共鳴通常是吃虧的。這正是設計文件裡擔心的問題：玩家會每回合都只選擴充。

| 規則 | 看手牌 vs 只擴充 |
|---|---|
| 目前規則 | 36% |
| 研讀抽 2 張 | 36% |
| 共鳴 +2 | 45% |
| 研讀抽 2 張＋共鳴 +2 | 41% |

光是調強研讀或共鳴，效果有限。可以考慮的方向：

- **A. 共鳴一次 +2**：最有效，但會讓「深岩」這副牌變得太強（見第 4 點）。
- **B. 前幾回合費用自動成長**：例如前 3 回合自動 +1，之後才開始三選一。這樣早期不會被迫選擴充。
- **C. 擴充延後生效**：擴充的費用下回合才能用，讓它有代價。
- **D. 強化共鳴卡的效果**：讓「共鳴 X」的回報更大，值得放棄一點費用。

### 3. 對局偏長

| 對局 | 平均總回合 | 估計時間 | 打到牌庫抽乾 |
|---|---|---|---|
| 烈風 vs 深岩 | 18～22 | 12～15 分鐘 | 20～50% |
| 烈風 鏡像 | 20 | 13 分鐘 | 33% |
| 深岩 鏡像 | 28 | 19 分鐘 | 82% |

兩副防守牌對打時，常常互相卡住路線，最後靠牌庫抽乾分勝負。
英雄改成 20 血可以縮短 1～2 回合，但對「深岩」的幫助不大。

### 4. 兩副牌不平衡

- **烈風（火 + 風）勝率約 63%**，比深岩（水 + 土）強。
- 最少被打出的卡牌：**古代守衛、大地之盾、岩石魔像、浪潮祭司**，都在深岩裡。
- 把共鳴改成 +2 之後，烈風勝率掉到 34%。這代表深岩的強度被鎖在共鳴後面：共鳴太難累積的時候，深岩就偏弱。

## 已經改了什麼

- 後手起始費用上限 1（第 1 點）。

## 建議下一步

1. 先決定第 2 點要用哪個方向（A～D 或其他想法），這是最影響遊戲手感的問題。
2. 再來調整卡牌數值，讓兩副牌接近 50 : 50。
3. 最後決定要不要用 20 血或其他方式縮短對局。
