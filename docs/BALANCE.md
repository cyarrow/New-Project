# 平衡模擬報告（v0.4）

讓兩個電腦玩家對打數百局，觀察規則和卡牌的平衡。
重新執行：`npm run simulate`（整體數據）、`npm run experiment`（比較不同規則）、`npm run matchups`（所有牌組兩兩對打）。

## 怎麼模擬的

- **電腦玩家**（`src/ai.js`）：每一步都試算所有合法行動，選讓局面分數最高的那個。分數看雙方血量、場上隨從、沒人擋的路線、手牌數。
- **成長策略**：
  - **看手牌**：手上有共鳴卡就累積共鳴，手牌快用完就研讀，其餘時候擴充。
  - **只擴充**：能擴充就擴充。
- 每組設定打 200～400 局。對局時間用「每回合 40 秒」粗估。

> **注意**：電腦玩家只會看眼前一步，不會規劃整個回合，也不會留牌。這些數字適合用來發現**明顯的問題**，最後還是要靠真人試玩確認手感。

## 目標

| 指標 | 目標 |
|---|---|
| 先手勝率（同牌組對打） | 45～55% |
| 烈風 vs 深岩 | 45～55% |
| 「看手牌」vs「只擴充」 | 接近 50%（代表三個成長選項都有用） |
| 一局時間 | 約 10 分鐘（平均總回合 ≤ 17） |
| 打到牌庫抽乾的比例 | 越低越好 |

先手勝率（三副牌各自鏡像戰的平均）：**46%**。

### 熔岩重裝的調整過程

1. **照提案的數值**：對烈風 49%，但對深岩 **71%**，太剋了。
2. **找出原因**：把每張卡輪流換成傭兵劍士，看勝率掉多少。
   - 拿掉**火山之心**掉最多（80% → 62%），其次是**熔岩巨像**（→ 68%）。原因是這兩張的身材相對費用太大，跟破守護的效果無關。
   - 拿掉**地脈震擊**反而變強（→ 96%），代表 4 費太貴，打出來不划算。
3. **調整**：

   | 卡牌 | 原本 | 調整後 |
   |---|---|---|
   | 火山之心 | 4/7，全體 +2 攻擊 | 3/5，全體 +1 攻擊 |
   | 熔岩巨像 | 6/7 | 5/6 |
   | 地脈震擊 | 4 費 | 3 費 |
   | 碎盾重擊 | 2 點傷害 | 1 點傷害 |

4. **起手張數**：三副牌的鏡像戰平均下來，後手勝率約 60%。改成雙方起手都是 3 張（後手原本 4 張）後，先手勝率回到 46%。

### 試過但沒採用的做法

| 做法 | 為什麼不用 |
|---|---|
| 岩漿蜥蜴對守護的加成 +2 → +1 | 勝率完全沒變（蜥蜴平均每 4 局才打一次守護） |
| 強化深岩（古代守衛 4/5、大地之盾 1 費） | 深岩對烈風變成 64% |

## 結果：v0.1 → v0.3

| 指標 | v0.1（原始） | v0.3（目前） |
|---|---|---|
| 先手勝率 | **67%** | 43% |
| 烈風勝率 | **66%** | 47% |
| 看手牌 vs 只擴充 | **35%** | 44% |
| 平均總回合 | 22（約 15 分鐘） | 16.4（約 11 分鐘） |
| 打到牌庫抽乾 | **45%** | 21% |

## v0.3 改了什麼

| 改動 | 解決的問題 |
|---|---|
| 前 3 回合費用上限自動 +1（照樣做成長選擇） | 開局不再被迫選擴充，研讀和共鳴變得有用 |
| 共鳴一次 +2（原本 +1） | 共鳴的回報太慢 |
| 後手起始費用 1；取消後手第一回合兩次選擇 | 先手優勢 |
| **控制路線**：回合開始時，每條只有自己有隨從的路線，對敵方英雄造成 1 點傷害 | 雙方互相卡路線，對局拖太長 |
| **穿透**：打死隨從後多出來的傷害打到英雄 | 同上 |
| 浪潮祭司、山脈巨龜的共鳴門檻 2 → 3 | 共鳴 +2 之後深岩太強 |

## 試過但沒採用的做法

| 做法 | 為什麼不用 |
|---|---|
| 擴充下回合才生效 | 「只擴充」反而更強（31%），對局也沒變短 |
| 費用全程自動成長，擴充變成額外加速 | 深岩太強（烈風只剩 18%），牌庫抽乾變多 |
| 前 3 回合自動成長、但那幾回合不做選擇 | 先手勝率在 22%～63% 之間大幅擺動，很難調 |
| 研讀改抽 2 張 | 牌庫抽乾變多（37～45%） |
| 英雄改 20 血 | 只縮短 1～2 回合，效果不如控制路線＋穿透 |
| 後手改成「第一回合暫時 +1 費」 | 先手勝率 57%，比目前的 43% 更偏 |
| 只調強烈風的隨從 | 會讓烈風太強（61%） |

## 還沒解決的問題

1. ~~後手稍微有利~~：v0.4 改成雙方起手 3 張後，先手勝率 46%。
2. **深岩鏡像戰太長**：兩副深岩對打平均 24 回合，82% 打到牌庫抽乾。熔岩重裝可以剋守護，但深岩對深岩本身還是會卡住。
3. **共鳴牌只有 3 張**：共鳴的價值很依賴牌組裡有多少共鳴卡。新構築應該讓每個元素都有 2～3 張共鳴卡。
